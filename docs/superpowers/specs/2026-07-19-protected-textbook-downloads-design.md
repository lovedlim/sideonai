# 비번으로 잠긴 교재 다운로드 페이지 — 설계 문서

- 날짜: 2026-07-19
- 대상 도메인: `go.sideonai.com`
- 기반: 기존 Next.js 16 (App Router) + Vercel 프로젝트 (`sideonai/`)

## 1. 목적

교재를 그냥 링크로 공유하는 대신, `go.sideonai.com`에서 교재 목록을 보여주고,
사용자가 항목을 고른 뒤 **자료마다 다른 6자리 영숫자 비밀번호**를 입력하면
그때만 구글 드라이브 다운로드 링크를 공개한다.

교재 목록은 **관리자 페이지**에서 폼으로 추가/수정/삭제한다 (JSON 직접 편집 없음).

## 2. 사용자 흐름

### 2.1 일반 사용자 (수강생)
```
go.sideonai.com
   → 교재 목록 (과정명 + 교육 기간 + 회사명 텍스트 카드)   ← 서버가 렌더 (비번/링크는 미포함)
   → 카드 클릭 → 모달로 비번 6자리 입력창
   → [확인] → 서버에 검증 요청
   → 성공: 다운로드 버튼(구글 드라이브 링크) 노출
   → 실패: "비밀번호가 틀렸습니다"
   → 반복 실패: 계단식 차단 + 남은 시간 표시
```

### 2.2 관리자 (본인)
```
go.sideonai.com/admin
   → (로그인 안 됨) 관리자 비번 입력 → 로그인
   → 교재 목록 (모든 필드 표시: 과정명/기간/회사명/링크/비번)
   → [추가] 폼: 과정명·기간·회사명·드라이브 링크 입력 + 비번 자동생성 버튼
   → [수정] / [삭제] 버튼
```

## 3. 핵심 보안 원칙

> **비밀번호와 드라이브 링크는 절대 일반 사용자 클라이언트로 전송하지 않는다. 서버에만 존재한다.**

- 공개 목록 페이지 HTML/JS에는 `id`, `course`, `period`, `company`만 포함.
- `url`(드라이브 링크)와 `password`는 서버 라우트에서만 읽고, 비번이 맞을 때만 `url`을 응답으로 반환.
- 관리자 페이지에서만 전체 필드가 보이며, 이 페이지는 **관리자 로그인으로 잠긴다**.
- 결과적으로 로그인 안 한 사람은 개발자도구/네트워크 탭으로 뒤져도 링크·비번을 볼 수 없다.

## 4. 데이터 저장 — Upstash Redis

관리자 페이지에서 데이터를 쓰기 때문에, 쓰기 가능한 저장소가 필요하다.
무차별 대입 방지에도 이미 Redis를 쓰므로 **Upstash Redis 하나로 통합**한다.
(Vercel 마켓플레이스, 무료 티어. Edge Config는 사용하지 않음)

### 4.1 교재 데이터
- Redis 해시 `textbooks`, 필드 = `id`, 값 = 항목 JSON 문자열.
- 항목 추가/수정 = `HSET`, 삭제 = `HDEL`, 목록 조회 = `HGETALL`.

```json
// textbooks 해시의 각 값
{
  "id": "kb2026",
  "course": "바이브코딩 과정",
  "period": "2026-03-01 ~ 2026-03-05",
  "company": "KB국민은행",
  "url": "https://drive.google.com/...",
  "password": "a1b2c3"
}
```

| 필드 | 성격 | 일반 사용자 노출 |
|---|---|---|
| `id` | 항목 식별자 (자동 생성) | O |
| `course` | 과정명 | O |
| `period` | 교육 날짜/기간 (자유 형식 문자열) | O |
| `company` | 회사명 | O |
| `url` | 구글 드라이브 링크 | **X (비밀)** |
| `password` | 6자리 영숫자 비번 | **X (비밀)** |

## 5. 구성 요소

### 5.1 공개 목록 페이지 (서버 컴포넌트) — `/`
- Redis `HGETALL textbooks` → 각 항목의 `id/course/period/company`만 텍스트 카드로 렌더 (썸네일 없음).
- `url/password`는 애초에 직렬화해서 내려보내지 않는다.

### 5.2 비번 검증 API — `POST /api/unlock`
- 요청: `{ id: string, password: string }`
- 처리:
  1. 요청 IP 확인 → `(ip, id)` 기준 차단 상태 확인. 차단 중이면 즉시 `429` + 남은 시간 반환 (비번 검사 안 함).
  2. Redis에서 `id`로 항목 조회 → `password` 대조.
  3. 일치: 실패 카운터 삭제 후 `200 { url }` 반환.
  4. 불일치: 실패 카운터 증가 → 새 누적값에 해당하는 차단 티어 적용 → `401 { blockedFor?: seconds }` 반환.
- 응답에는 성공 시에만 `url` 포함.

### 5.3 잠금 해제 UI (모달 컴포넌트, 클라이언트)
- 카드 클릭 → 모달 오픈 → 6자리 입력.
- `/api/unlock` 호출 → 성공 시 다운로드 버튼(새 탭으로 드라이브 링크) 표시.
- `401` → "비밀번호가 틀렸습니다", `429` → "너무 많이 시도했어요. N분 후 다시 시도하세요".

### 5.4 관리자 페이지 — `/admin`
- 로그인 안 된 상태: 관리자 비번 입력 폼만 표시.
- 로그인 된 상태:
  - 교재 목록 (전체 필드 표시).
  - **추가 폼**: 과정명 / 교육 기간 / 회사명 / 드라이브 링크 입력. **비번 자동생성 버튼**(6자리 영숫자 랜덤, 수동 수정도 가능).
  - **수정 / 삭제** 버튼.
- 관리 동작은 관리자 전용 API 라우트를 통해 수행하며, 모든 관리자 API는 로그인 세션을 검사한다.

### 5.5 관리자 인증 (단일 비밀번호)
- 계정 시스템 없이 **관리자 비번 하나**로 문을 잠근다.
- `ADMIN_PASSWORD` 환경변수에 관리자 비번 저장.
- 로그인 성공 시 **서명된 httpOnly·Secure·SameSite=Strict 쿠키**(세션 토큰) 발급.
  세션 토큰은 `SESSION_SECRET` 환경변수로 HMAC 서명하고 만료시간을 포함한다.
- `/admin` 페이지와 모든 관리자 API 라우트는 이 쿠키의 서명·만료를 검증한다.
- 관리자 로그인도 아래 무차별 대입 방지(6절)를 IP 기준으로 동일하게 적용한다.

## 6. 무차별 대입 방지 — Upstash Redis

Vercel 서버리스는 요청마다 상태가 초기화되므로 실패 횟수는 공용 저장소(Redis)에 기록한다.

### 6.1 카운팅 단위
- 교재 비번: `(ip, itemId)` 조합. 한 교재에 대한 실패가 다른 교재를 잠그지 않는다.
- 관리자 로그인: `(ip, "admin")` 조합.

### 6.2 계단식 차단 규칙 (누적 실패 기준)
| 누적 실패 | 차단 시간 |
|---|---|
| 5회 이상 | 1분 |
| 10회 이상 | 3분 |
| 15회 이상 | 10분 |
| 20회 이상 | 1시간 |

- 실패할 때마다 카운터 증가. 새 누적값이 티어 임계치(5/10/15/20)를 넘으면 해당 차단 시간만큼 `blockUntil` 설정.
- 차단 중 요청은 즉시 거절(`429`)하며 카운터를 올리지 않는다.
- 차단이 풀린 뒤의 추가 실패는 기존 누적값에서 계속 이어져 다음 티어로 상승한다.

### 6.3 리셋
- 비번을 맞히면 해당 카운터·차단 정보 삭제.
- 실패 카운터 키 TTL = 1시간 (실패 기록 시마다 갱신). 1시간 동안 시도가 없으면 자동 리셋.

## 7. 도메인/배포
- `go.sideonai.com`을 기존 Vercel 프로젝트에 도메인으로 연결하고, 이 기능을 해당 도메인 루트에서 제공.
- 필요한 환경변수:
  - Upstash Redis 연결 (마켓플레이스 설치 시 자동 주입).
  - `ADMIN_PASSWORD` — 관리자 로그인 비번.
  - `SESSION_SECRET` — 관리자 세션 쿠키 서명 키.

## 8. 범위 밖 (YAGNI)
- 다중 관리자 계정/권한 (관리자 비번 하나로 충분).
- 다운로드 횟수 통계/로그.
- 파일 자체 호스팅 (구글 드라이브 링크만 사용).

## 9. 구현 규모 요약
기존 앱에 추가되는 것:
- 공개 목록 페이지 1개 + 비번 모달 컴포넌트 1개
- 비번 검증 API `/api/unlock` 1개
- 관리자 페이지 `/admin` (로그인 + 목록 + 추가/수정/삭제 폼)
- 관리자 인증 API + 관리자 CRUD API
- Redis 유틸(교재 CRUD, 무차별 대입 카운터), 세션 서명 유틸

인프라: Upstash Redis 1개(무료). Edge Config 불필요.
